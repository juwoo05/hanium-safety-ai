건설현장 안전관리 플랫폼 “안전고리”의 AI 위험요소 분석, 조치 검증, 보고서 생성, 신고 기능 화면을 만들어줘.

이 화면은 실제 API 연결이 아니라 mock data 기반의 프로토타입이다.
Roboflow 1차 객체인식 검증, AI 2차 판독 검증, 전후 사진 비교, 조치 완료율 게이지, AI 결과보고서 생성, 신고 사진 첨부 기능이 한 흐름으로 이해되게 만들어줘.

전체 UI는 Spring Boot + Thymeleaf 기반 관리자 웹 서비스처럼 구성해줘.
마케팅 페이지가 아니라 실제 현장관리자가 쓰는 업무용 관리자 화면처럼 깔끔하고 실무적으로 디자인해줘.

주요 목적:
- 현장 사진 업로드
- Before / After 사진 비교
- Roboflow 객체인식 1차 검증
- AI 판독 2차 검증
- AI가 전후 사진 비교 결과를 가상 이미지/시각화로 보여줌
- 조치 내용 적합성 판단
- 완료율 게이지 표시
- 관리자가 애매한 항목 수정 가능
- 완료율 100%가 되어야 조치 완료 처리 가능
- AI 결과보고서 양식 파일 업로드 및 PDF 생성
- 신고 시 사진 첨부 가능

전체 화면 구성은 다음 섹션 또는 탭으로 나눠줘.

화면 제목:
- AI 위험요소 분석 및 조치 검증

상단에는 현장 선택 영역을 만들어줘.
- 현장명
- 원청 건설사
- 하청 업체
- 점검일
- 담당자

mock 데이터:
- 현장명: 강남 복합시설 신축공사
- 원청 건설사: 대한안전건설
- 하청 업체: 안전하도급
- 점검일: 2026.08.09
- 담당자: 이조치

사진 업로드 영역:
- Before 사진 업로드
- After 사진 업로드
- 드래그 앤 드롭 업로드 박스
- 파일 선택 버튼
- 업로드된 이미지 미리보기
- Before / After 사진을 좌우 비교 형태로 보여줘
- 두 사진 사이에는 비교 아이콘 또는 화살표를 넣어줘

Before 예시:
- 작업 전: 안전난간 미설치, 개구부 방치, 안전모 미착용 작업자 감지

After 예시:
- 작업 후: 안전난간 설치, 개구부 덮개 설치, 안전모 착용 확인

2. Roboflow 1차 객체인식 검증

Roboflow 분석 결과 섹션을 만들어줘.
제목:
- 1차 검증: Roboflow 객체인식

카드 또는 표 형태로 다음 항목을 보여줘.
- 감지 객체
- 위치
- 신뢰도
- 위험 등급
- 상태

mock 데이터:
1. 안전난간 미설치 / 좌측 상단 / 94% / 높음 / 조치 필요
2. 개구부 방치 / 중앙 하단 / 91% / 높음 / 조치 필요
3. 안전모 미착용 / 우측 작업자 / 88% / 중간 / 조치 필요

이미지 위에는 객체인식 박스가 보이는 것처럼 표현해줘.
- 빨간 박스: 위험요소
- 초록 박스: 조치 완료된 요소
- 노란 박스: 확인 필요 요소

3. AI 2차 판독 검증

AI 판독 결과 섹션을 만들어줘.
제목:
- 2차 검증: AI 판독 및 전후 비교

AI가 Before / After 사진을 비교해서 다음 결과를 보여주는 형태로 만들어줘.

항목:
- 위험요소명
- Before 상태
- After 상태
- AI 판정
- 권장 조치
- 조치 적합도
- 관리자 확인 상태

mock 데이터:
1. 안전난간 미설치
   - Before: 난간 미설치로 추락 위험 있음
   - After: 임시 안전난간 설치 확인
   - AI 판정: 조치 적합
   - 권장 조치: 난간 고정 상태 추가 확인
   - 조치 적합도: 92%
   - 관리자 확인 상태: 완료 가능

2. 개구부 방치
   - Before: 개구부 덮개 없음
   - After: 덮개 설치 확인되나 고정 여부 불명확
   - AI 판정: 추가 확인 필요
   - 권장 조치: 덮개 고정 클램프 확인 사진 추가 필요
   - 조치 적합도: 67%
   - 관리자 확인 상태: 관리자 수정 필요

3. 안전모 미착용
   - Before: 작업자 1명 안전모 미착용
   - After: 작업자 안전모 착용 확인
   - AI 판정: 조치 적합
   - 권장 조치: 지속 착용 교육 기록 첨부
   - 조치 적합도: 88%
   - 관리자 확인 상태: 완료 가능

4. AI 전후 비교 이미지화 영역

제목:
- AI 전후 비교 시각화

AI가 판독한 내용을 시각적으로 보여주는 mock 이미지 영역을 만들어줘.
- Before 이미지
- After 이미지
- AI 비교 결과 이미지
- 위험요소별 색상 마킹
- 조치된 항목에는 초록 체크 표시
- 미흡한 항목에는 노란 경고 표시
- 미조치 항목에는 빨간 경고 표시

비교 요약 문구:
- AI가 전후 사진을 비교한 결과, 3개 위험요소 중 2개는 조치 적합, 1개는 추가 확인이 필요합니다.
- 완료율이 100%가 되어야 최종 완료 처리할 수 있습니다.

5. 조치 완료율 게이지

제목:
- 조치 완료율

큰 프로그레스 게이지를 만들어줘.
- 현재 완료율: 82%
- 완료 가능 기준: 100%
- 상태: 관리자 확인 필요

게이지 규칙:
- 조치내용이 AI 판독 결과와 적합하면 자동으로 완료 처리되고 완료율이 올라간다.
- 애매하거나 부족한 항목은 “관리자 수정 필요”로 표시된다.
- 관리자가 조치 내용을 수정하거나 보완 확인을 하면 완료율이 다시 계산된다.
- 완료율이 100%가 되어야 “최종 조치 완료” 버튼이 활성화된다.

버튼 상태:
- 완료율 82%일 때: 최종 조치 완료 버튼 비활성화
- 완료율 100%일 때: 최종 조치 완료 버튼 활성화

관리자 수정 UI:
- 위험요소별 조치내용 수정 입력창
- 관리자 판정 셀렉트바
  - 완료
  - 추가 확인 필요
  - 반려
- 보완 사진 추가 버튼
- 수정 저장 버튼
- 재검증 요청 버튼

6. AI 결과보고서 생성 화면

서류 생성은 Wizard Step UI로 만들어줘.

제목:
- AI 결과보고서 생성

설명:
- 업로드한 양식 파일을 기반으로 AI가 현장 점검 결과보고서를 자동 생성합니다.

Wizard Steps:
1단계: 양식 파일 넣기
2단계: 양식 선택
3단계: AI 양식 파일 생성
4단계: 저장하기 및 PDF 생성

각 단계 화면을 보여줘.

1단계: 양식 파일 넣기
- 보고서 양식 파일 업로드 영역
- 지원 형식:
  - DOCX
  - HWP
  - PDF
  - XLSX
- 버튼:
  - 파일 선택
  - 양식 업로드
- 업로드된 파일명 예시:
  - 안전점검_결과보고서_양식.docx

2단계: 양식 선택
- 업로드한 양식 목록 카드
- 기본 제공 양식 목록
- 양식 미리보기
- 선택 버튼
- mock 양식:
  - 안전점검 결과보고서
  - TBM 보고서
  - 위험요소 조치결과 보고서
  - 하청 조치확인서

3단계: AI 양식 파일 생성
- AI가 선택된 양식에 맞춰 다음 내용을 자동 삽입하는 화면
  - 현장명
  - 점검일
  - 원청 건설사
  - 하청 업체
  - 위험요소 목록
  - Before / After 사진
  - Roboflow 객체인식 결과
  - AI 2차 판독 결과
  - 조치 완료율
  - 관리자 수정 내역
  - 최종 조치 상태
- 생성 진행률 바
- AI 생성 중 상태
- AI 생성 완료 상태
- 보고서 미리보기 영역

4단계: 저장하기 및 PDF 생성
- 저장 버튼
- PDF 생성 버튼
- 다운로드 버튼
- 보고서 저장 위치 표시
- 생성된 파일명 예시:
  - 강남복합시설_안전점검_AI결과보고서_20260809.pdf
- 상태 배지:
  - 저장 완료
  - PDF 생성 완료

9. 디자인 요구사항

- 업무용 관리자 화면처럼 정돈된 레이아웃
- 너무 화려한 랜딩페이지 스타일 금지
- 카드, 표, 게이지, 업로드 박스, 상태 배지, Wizard Step을 사용
- 안전관리 서비스에 맞는 navy, white, gray, green 색상 사용
- 위험/반려/미조치 상태는 red
- 확인 필요/애매함은 yellow
- 완료/적합 상태는 green
- AI 분석 영역은 기술적인 느낌이 나도록 정돈
- Before / After 사진 비교 영역은 가장 눈에 잘 띄게 구성
- 프로그레스 게이지는 완료율을 직관적으로 보여줘
- 관리자 수정 가능 영역은 실제로 입력 가능한 폼처럼 보여줘
- 모바일에서는 섹션들이 세로로 자연스럽게 쌓이게 반응형으로 구성
